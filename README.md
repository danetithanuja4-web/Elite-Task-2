# Elite Task-2

Personal portfolio demo built with HTML, CSS, and JavaScript.

## Overview

- Single-page portfolio layout
- Hero section with custom canvas animation
- About, Projects, Skills, and Contact sections
- GSAP + ScrollTrigger animations
- Three.js background canvas

## Files

- `Index.html` - main markup
- `style.css` - styles and responsive layout
- `script.js` - interactive behavior and animations

## Local setup

1. Clone the repo
2. Open `Index.html` in a browser

## Notes

- Contact form currently has no backend handler (`onsubmit="return false;"`).
- Update the placeholder copy (name, email, links) for your own portfolio.
